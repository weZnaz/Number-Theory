# Reference repository inspection summary

This project is based on a study of the workshop repository maintained by the Maths and Physics Club, IIT Bombay. The reference material emphasizes a practical introduction to number theory and cryptography using Python notebooks, assignments, and study resources.

## Topics observed in the reference workshop

1. Divisibility and arithmetic foundations
2. Prime numbers and composite numbers
3. Prime factorization
4. GCD and Euclidean algorithm
5. Extended Euclidean algorithm and modular inverse
6. Congruence and modular arithmetic
7. Fermat's little theorem and Euler's theorem
8. Euler's totient function
9. Chinese remainder theorem
10. Classical ciphers and public-key cryptography
11. RSA and practical cryptography examples

## Scope of this project

This repository covers the same conceptual core in a clearer academic format and uses original implementations, explanations, examples, and tests rather than a direct copy of the source notebooks.
